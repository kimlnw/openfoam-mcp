The pure-Python tools are covered by 27 unit tests. Beyond that, the OpenFOAM
integration was validated **end-to-end against a real OpenFOAM installation**
(ESI OpenFOAM **v1912**, Ubuntu 24.04) — cases generated by the MCP were run
through `blockMesh` and the solvers, and the real output logs were fed back into
the MCP's own parsers.

## Issues found by live testing and fixed

Live testing caught three real template bugs that unit tests could not, all now
fixed and re-verified:

1. **Turbulence dictionary name.** OpenFOAM ≤ v1912 / Foundation ≤ v7 read
   `constant/turbulenceProperties` (`RASModel`), while newer versions read
   `constant/momentumTransport` (`model`). The scaffolder now emits **both**, so
   a generated case runs on either lineage.
2. **`wallDist` scheme required.** k-ω SST needs a `wallDist { method meshWave; }`
   entry in `system/fvSchemes`; it was missing and the solver aborted. Added.
3. **Transient `fvSolution`.** `icoFoam` needs a `PISO` block (not `PIMPLE`), and
   PIMPLE/PISO runs need `pFinal`/`UFinal` solver entries. `fvSolution` is now
   generated correctly per algorithm.

## Foundation v11/v12 (`foamRun`) flavor — v1.0.0

`scaffold_case(..., openfoam_flavor="foundation-v12")` emits the modular-solver
case style used by OpenFOAM Foundation v11/v12: `application foamRun;` +
`solver incompressibleFluid;`, with `constant/physicalProperties` instead of
`transportProperties`. Because the Foundation v12 package is not reachable from
the build sandbox, this flavor is validated by **syntax-checking every generated
dictionary with `foamDictionary`** and confirming the case meshes, rather than by
a live solve:

| Check (v12 flavor) | Result |
|--------------------|--------|
| `controlDict` → `application` / `solver` | `foamRun` / `incompressibleFluid` |
| `constant/physicalProperties` parses (`nu`) | OK — `[0 2 -1 0 0 0 0] 1.5e-05` |
| `constant/momentumTransport` parses (`simulationType`) | OK — `RAS` |
| `system/fvSolution` `SIMPLE` block parses | OK |
| `blockMesh` on the v12-flavor case | OK (400 cells) |
| icoFoam→v12 uses `PIMPLE` (not `PISO`) | OK |

## Version compatibility

- **Certified by live solve:** ESI OpenFOAM **v1912** (classic flavor).
- **Classic flavor** (`openfoam_flavor="classic"`, default): works on ESI v2006+
  and OpenFOAM Foundation v8–v10, and on ≤ v1912 / Foundation ≤ v7 thanks to the
  dual turbulence-dictionary output.
- **Foundation v11/v12** (`openfoam_flavor="foundation-v12"`): dictionaries
  syntax-validated with `foamDictionary`; run `foamRun` instead of the solver
  name. Recommend one confirmation solve on your v12 machine before relying on it
  in production.
